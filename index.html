Process

From idea
to experience.

I like to understand the problem before deciding how it should look. My process moves from structure and intention into design, implementation, and refinement.

01

Discover

Understand the goals, audience, content, and project needs before deciding on a visual direction.

02

Structure

Organize navigation, hierarchy, content, and user flows to create a clear foundation for the experience.

03

Design

Develop the visual direction through typography, color, layout, responsive behavior, and interface decisions.

04

Implement

Bring the approved design into a functional website using the platform or development approach suited to the project.

05

Refine

Test, adjust, simplify, and polish the final experience across devices before launch.
